Mini Issue Tracker — UX/UI Design

Практична робота
Тема: Проєктування UX/UI інтерфейсу Mini Issue Tracker
Форма виконання: індивідуальна

Мета роботи

Розробити low-fidelity wireframes та клікабельний прототип вебзастосунку Mini Issue Tracker відповідно до наданих функціональних вимог.

Опис проєкту

Mini Issue Tracker — система для створення, перегляду та відстеження задач і проблем у невеликій команді розробників.

У межах практичної роботи розроблено:

Екран загального списку заявок (All Issues).

Екран важливих заявок (Important Issues).

Порожній стан списку (Empty State).

Форму створення заявки та повідомлення про помилки.

Екран деталей заявки (Issue Details).

Стани додавання коментаря та обробки помилок.

Приклади прав доступу користувачів і переходів між статусами.

Клікабельні переходи між основними екранами.

Інструменти

Figma, Figma Agent, ChatGPT, GitHub.

Структура репозиторію

docs/ — вимоги, UX-рішення, опис екранів, звіти та журнали перевірок.

evidence/ — скриншоти розроблених екранів.

README.md — загальна інформація про практичну роботу.

Результат

Створено редагований low-fidelity макет та клікабельний прототип Mini Issue Tracker. Основні сценарії представлені у вигляді окремих екранів і демонстраційних переходів.

Прототип призначений для демонстрації UX/UI-рішень і не передбачає серверного збереження даних.
